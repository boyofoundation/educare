## 每筆問題的回報格式

```text
編號：UX-001
標題：
影響：阻擋任務／可繞過但困難／外觀或文案
環境：裝置、OS、瀏覽器版本；若使用 VoiceOver 請註明
顯示設定：直向或橫向、主題、閱讀字級、縮放比例
所在流程：導覽／助理／模型設定／聊天／作品／分享／備份與恢復／離線更新／備課與練習／Agent 續跑
前置條件：新使用者或既有資料；是否離線、是否開啟軟鍵盤
重現步驟：
預期結果：
實際結果：
重現頻率：例如 3 次中 2 次
證據：截圖或錄影（遮蔽 API key、聊天個資與私人教材）
暫時繞過方式：
```

不需要提供真實 API key；回報模型問題時提供供應商／模型名稱及已遮蔽的錯誤即可。
資料遺失或無法繼續任務優先處理，其他項目按影響與重現性排序。

## 改善追蹤

### 功能與教學回饋（F1–F6）

以下由使用者後續安排，不以 Agent fixture 或瀏覽器模擬冒充真人驗收：

- 5 位教師各試做一份教材：記錄題目／答案／解說、來源標示、編輯及練習流程需要修正之處。
- 搜尋品質：由教師檢閱至少 50 題中英文查詢及正確來源標註，另記錄無答案題；目前自動化資料集為 Agent 建立的固定回歸 fixture，不是人工研究結果。
- iOS／Android：安裝、網站儲存限制、真正飛航模式冷開、更新和檔案分享；記錄 OS／瀏覽器版本與是否曾清除網站資料。
- VoiceOver：資料管理預覽／恢復、練習題組與 Agent 預算／續跑控制的名稱、狀態播報及焦點順序。
