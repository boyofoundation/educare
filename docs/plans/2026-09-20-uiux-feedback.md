# UI／UX 後續驗收與改善回報

依 2026-09-20 使用者指示，首次使用者試用、iOS／Android 實機與 VoiceOver
由使用者後續處理，不阻擋本次 Agent 工程交付。此文件保留回報與修正追蹤空間，
空白或「待測」不代表通過；自動化結果另見[驗證紀錄](./2026-09-20-uiux-validation.md)。

測試版本：`uiux/frontend-improvements-20260920`（開始測試時填入 commit：＿＿＿＿）

## 每筆問題的回報格式

```text
編號：UX-001
標題：
影響：阻擋任務／可繞過但困難／外觀或文案
環境：裝置、OS、瀏覽器版本；若使用 VoiceOver 請註明
顯示設定：直向或橫向、主題、閱讀字級、縮放比例
所在流程：導覽／建立或編輯助理／模型設定／聊天／作品／分享
前置條件：新使用者或既有資料；是否離線、是否開啟軟鍵盤
重現步驟：
預期結果：
實際結果：
重現頻率：例如 3 次中 2 次
證據：截圖或錄影（遮蔽 API key、聊天個資與私人教材）
暫時繞過方式：
```

不需要提供真實 API key；回報模型問題時提供供應商／模型名稱及已遮蔽的錯誤即可。
資料遺失或無法繼續任務優先處理，其他項目按影響與重現性排序。
